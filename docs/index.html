What is in the box

An instrument, not a demo page

Everything below is running in the tab you are about to open. No frameworks, no CDN, no telemetry, no cookies.

27 procedurally synthesised loops

Kicks, snares, hats, 808s, stabs, arps, pads, bells, risers, scratches and vinyl beds — rendered offline at boot, so they are real audio buffers you can trim, loop and time-stretch.

Canvas arrangement timeline

Drag to move, drag the edges to trim, alt-drag to duplicate, split at the playhead, nudge, quantise. Rendered in a viewport-sized canvas, so a 64-bar project stays smooth at any zoom.

Mixer with live meters

Per-track fader, pan, delay and reverb sends, mute and solo, plus a real-time level meter on every strip and on the master bus. Mute is a gain change, so it silences audio that is already playing.

Master FX rack

Three-band EQ, tempo-synced delay, convolution reverb with a synthetic impulse, bitcrusher and a limiter. Double-click any knob to reset it.

WAV export that matches what you hear

The arrangement is re-rendered through an identical offline graph — same EQ, same reverb buffer, same limiter — then written as 16-bit PCM WAV. Bounce the loop region for a sample pack.

Bring your own audio

Drop WAV, MP3, OGG, FLAC or M4A files anywhere in the window. Imported samples are stored in IndexedDB with your project, so they survive a reload.

Works with the network off

A service worker caches the shell, so the app opens and plays with no connection. Install it from the browser menu and it runs like a native app.

Built for thumbs as well as mice

Phone, tablet and desktop layouts are designed separately. Tab bar, bottom sheets, 40 px+ targets, long-press for clip actions and a scroll/edit switch for the timeline.

Autosave, undo and redo

Every edit lands in a named history panel you can jump back through — Split clip, Nudge clip, Paste clip — and the whole project autosaves to IndexedDB 650 ms after you stop touching it.

Scenes

Save the arrangement as a named snapshot — clips, mixer, automation, loop, tempo — then switch between sections live. A launch while rolling waits for the next bar, so it lands on a downbeat.

Plug in a controller

Web MIDI: notes 36–51 fire the first sixteen pads with velocity, 52 starts and stops, 53 rewinds. CC learn maps any knob to any rack or mixer control. Opt-in, and nothing leaves the machine.

Rendered once, then instant

The 27 loops are cached in IndexedDB as 16-bit mono. A cold start synthesises them; every start after that is a memory copy — about 1.6 s instead of 4.7 s, with half the library ready before the loading veil lifts.

Pitch, reverse, fades, swing, stems

Flip a clip's pitch by up to an octave, play it backwards, shape fade in/out envelopes, push the whole groove with swing — then bounce one WAV per track as a zip.

Get it

Four ways to run it

1 · Just open it

Click Launch the app. Nothing installs, nothing leaves the tab.

2 · One file, no server

Download neonboom.min.html (177 KB) and double-click it. The whole workstation — CSS, JS, icons — is inside that one file and runs from file://. Prefer to read the code? neonboom.html is the same app, unminified.

3 · Skip the wait (optional pack)

A separate 6.9 MB zip holds the same 27 loops, rendered by the app itself. Bundled builds load it automatically; in the browser, open Export → Load sample pack. The core file stays 192 KB either way.

4 · Install as an app

Open the hosted app, then use your browser's Install / Add to Home Screen. It launches full-screen and works with the network off.

5 · Desktop & Android builds

Installers are built by CI from every tag and attached to Releases: Windows .exe, macOS .dmg (Intel + Apple Silicon), Linux .AppImage / .deb, and an Android .apk (debug, unsigned).

Or build them yourself:

# Windows / macOS / Linux desktop
cd electron && npm install && npm run dist

# Android (Capacitor, needs Android Studio)
npm install && npx cap add android && npx cap sync

These builds are unsigned, so your OS will warn on first launch. The web app is the product; the wrappers exist so you can pin it to a dock or a home screen.

Status

Finished, and staying finished

Shipped by 2.4.0

  • 27 synthesised loops, pad grid, canvas arrangement
  • Mixer with per-track delay and reverb sends
  • Master FX rack, automation lanes for level and pan
  • Clip editor, stem export, WSOLA tempo-fit
  • Scenes with quantised live switching
  • MIDI notes, velocity and CC learn
  • Offline PWA, 192 KB single file, desktop + Android builds

Deliberately not planned

  • Accounts, cloud sync or telemetry — the app has no server
  • Sample-store browsing — it works offline by design
  • A plugin format — the browser is the host
  • Video tutorials baked into the UI
  • Code signing — needs certificates held as secrets
  • Translations — only worth it with a domain translator

The reasoning for each closed item is in ENHANCEMENTS.md §9.
